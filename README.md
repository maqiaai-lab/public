## How We Work

A four-phase engagement, run hands-on. Developers work directly with your team — no layers, no handoffs.

**01 — Discovery**
You tell us what's broken, in your words. We embed in your operations to map workflows, data handoffs, and the workarounds your team has built to cope. The phase ends with a named problem and a build plan.

**02 — Build**
We design and construct a system informed entirely by discovery. Development runs in tight cycles with real-time feedback and steering, so the solution stays yours — not a template variant.

**03 — Deploy & Validate**
Live on real work from day one: real transactions, real documents, real users. We measure impact against the problem we named in discovery — not generic feature metrics.

**04 — Evolve**
Ongoing partnership: model retraining, new capabilities, and continuous adaptation as your operations change. A system that keeps fitting.

## maqia Studio — Our Foundation Platform

Every bespoke build starts on maqia Studio, the in-house platform that lets us move from discovery to a working system fast — without cutting corners on a custom fit.

| Layer | What it provides |
|-------|------------------|
| **Design System** | 50+ themeable components — tables, forms, dashboards, document viewers, chat surfaces |
| **AI Integrations** | Pre-built model interfaces and connectors, ready to wire into your data |
| **Roles & Access** | Authentication, permissions, and role-based access frameworks |
| **Conversational Layer** | Agent behavior and human-in-the-loop interaction scaffolding |

The Studio is the accelerator. The system we build on top of it is yours.
